## Overview

This is an ongoing cybersecurity home lab that I use to practice networking, system hardening, and defensive security workflows in an isolated environment.

The lab is built around Linux and Windows virtual machines, with tools like wireshark helping me observe traffic, understand network behavior, and experiment with security-focused configurations.

## What I'm Building

The goal of this project is to create a safe environment where I can break, inspect, fix, and better understand systems without affecting my main devices or home network.

Some of the areas I’m focusing on include:

- Linux and Windows administration
- Network traffic analysis
- DNS-level filtering and visibility
- Virtualized lab environments
- Defensive security fundamentals
- System hardening practice

## What I’m Learning

This project is helping me connect networking and security concepts to real systems. Instead of only reading about services, ports, traffic, and logs, I can actually observe how they behave and how small configuration choices affect the environment.
